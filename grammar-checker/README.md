# English Learning Practice Tool

This repository provides an interactive practice tool designed specifically for English learners to improve their language skills.

### ✨ Current Features
* **Writing Optimization:** Enhances sentence structure, readability, and overall flow.
* **Grammar Checking:** Quickly identifies and corrects grammatical errors.
* **Proper Word Usage:** Provides feedback on vocabulary to ensure accurate and contextual word choices.

### 🚀 Future Updates
This project is under active development. We will continuously expand the platform with exciting new features and tools to further support your English learning journey. Stay tuned!

## 🛠️ How to Run Locally

Follow these steps to run the application on your local machine:

### 1. Clone the repository
```bash
git clone [https://github.com/subejsb7002/Englishlearning.git](https://github.com/subejsb7002/Englishlearning.git)
cd Englishlearning
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure API Key
1. Copy the example environment file:
   * Windows: `copy .env.example .env`
   * Mac/Linux: `cp .env.example .env`
2. Open the `.env` file and replace `your_api_key_here` with your own API key.

### 4. Start the server
```bash
node server.js
```
Open your browser and navigate to `http://localhost:3000` to start using the tool!
